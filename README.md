# Belgian Energy Data Pipeline

A reproducible data engineering project using Belgian
electricity grid data published by Elia.

## Objectives

- Ingest historical and regularly updated datasets
- Validate data quality and temporal consistency
- Store and transform data using Python and SQL
- Build an analytical data model
- Visualize electricity load and forecast accuracy
  with Power BI
- Explore future migration to Microsoft Fabric

## Data sources

- Elia Open Data
- Initial dataset: ODS001
- Source: https://opendata.elia.be/explore/dataset/ods001/

## Status

Phase 1 — Data source qualification and profiling.

## Technology stack

Python, SQL, Git, Power BI.

Database engine to be selected after initial profiling.
